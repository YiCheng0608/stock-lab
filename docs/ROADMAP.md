# 產品路線與能力邊界

本文件管理產品方向及未完成核心，已驗能力見[目前產品能力](CAPABILITIES.md)；版本任務在 GitHub milestone，排序與狀態在 Issues／Projects（入口見[工作手冊](WORKFLOW.md#欄位與唯一來源)）。流程依 [AGENTS](../AGENTS.md)。

## V2 方向

使用者 2026-11-11 核定（雲端 session 的架構檢視後；統籌記入 [#1](https://github.com/YiCheng0608/stock-lab/issues/1) 決策索引）。V1 做到每天產出一份名單；V2 的目標是：**每一檔被選出來的股票都說得出依據，而且依據有歷史數字支持。** 產品定位不變：以資料與情報選出下一個交易日可以考慮進場的股票，並給進場、停損與目標價位；月營收、財報等基本面可以成為條件，但每一項都先有證據才納入。什麼算證據、研究怎麼做見[策略證據](spec/evidence.md)。

| 階段 | 完成後使用者得到什麼 | 內容 | 前提 |
| --- | --- | --- | --- |
| 一、知道現況 | 知道現在這套名單有沒有贏過大盤、每個條件有沒有用 | 候選成績單（上線以來的名單對同日母體與加權指數的事後表現）；特徵證據（現行條件與價量、籌碼、月營收、季報 EPS 各特徵的預測力）。[#619](https://github.com/YiCheng0608/stock-lab/issues/619) | 無 |
| 二、依證據重做選股與進出場 | 名單的排序與進出場規則有數字依據 | 評分改版（權重依證據訂；沒有證據的分項拿掉或只顯示；有證據的特徵加入，升版）；出場規則研究（固定目標一出場對比移動停利與時間出場）；組合層級回測（每天買前 N 檔、持有 K 天的資金曲線對加權指數，含實際成本與漲停買不到）；歷史回補到 5 年以上 | 階段一的結果；歷史回補的範圍與來源由使用者另行決定 |
| 三、把依據做進產品 | 在畫面上看得到每一檔為什麼被選、這套系統最近準不準、買了之後該怎麼辦 | 每檔候選的理由旁標示有無歷史證據；成績單做成頁面、每月更新；持倉管理（續抱、減碼、出場的每日提示） | 階段二 |

### 階段一的成功標準

跑之前固定，看完結果不改（[研究規則](spec/evidence.md#研究規則)第 3 條）。數字出自[候選成績單](spec/evidence.md#兩個問題兩個工具)，t 值是該文件定義的保守值。

| 判定 | 條件 |
| --- | --- |
| 名單有效 | 候選累積至少 60 個交易日；T+20 對同日母體平均的超額報酬 > 0 且 t ≥ 2；對加權指數的超額報酬 > 0；T+5 的超額報酬同號 |
| 排序有效 | 同上的樣本下，總分與之後報酬的每日排序相關平均 > 0 且 t ≥ 2 |
| 方向一致但不顯著 | 超額報酬 > 0 但 t < 2：不下結論，每月重跑累積 |
| 無效 | 至少 60 個交易日後，T+20 對同日母體的超額報酬 ≤ 0 |
| 樣本不足 | 不到 60 個交易日：只記錄，不判定 |

候選名單上線不久（起訖日以成績單報告為準），滿 60 個交易日之前一律是「樣本不足」；早期的依據以特徵證據（2024-09-30 起）為主。

### 結果不如預期時

依序處理，每一步的結果都在 [#1](https://github.com/YiCheng0608/stock-lab/issues/1) 回報：

1. 現行條件裡「沒有證據」或「驗證段反轉」的，提案移除或改為只顯示，由使用者決定。
2. 特徵裡有「有證據」的，照階段二用它們重做評分；現行兩條進場規則不是前提，可以整組換掉。
3. 特徵與名單都沒有證據時，停止策略研究並回報使用者。產品改以篩選與紀律為主：首頁維持「今日名單」、不顯示任何預期報酬或勝率，工作轉到出場規則、部位與風險、每日提醒；要不要回補歷史再驗一次由使用者決定。

### 階段二的先後

1. **出場規則**：不需要新資料，用現有研究回測比較固定目標一、移動停利與時間出場。
2. **組合層級回測**：衡量第 1 項與之後每一項有沒有用的尺。
3. **評分改版**：依階段一的特徵證據。
4. **歷史回補**：前三項的結論在兩年資料上站不穩時才做；範圍與來源由使用者決定。

### 部位與風險（階段三）

使用者設定每筆願意承擔的損失金額後，候選才顯示建議張數（金額 ÷（進場價 − 停損價），無條件捨去到整張）；沒有設定就不顯示張數（[PRODUCT_SPEC §5](PRODUCT_SPEC.md#5-一檔一張行動摘要與完整交易計畫)）。同一天多檔候選屬於同一族群時提示曝險重疊，不把它們當成各自獨立的機會。

### 未排入的候選方向

排入前各自先開單評估，由使用者決定：

- **開盤前檢查**（使用者 2026-11-11 提出，排在今日名單改版之後）：21:30 之後到隔天開盤前的新聞（含美股盤中）目前不會進當晚的名單。每個交易日開盤前對前一晚的名單再看一次：列出每檔的隔夜新聞與 AI 判讀、隔夜美股與對應族群的指數。先只顯示、不改分數與排序，並把每天的結果存下來；累積後以成績單比較隔夜有利空與沒有的候選，有差距才讓它影響排序。AI 判讀維持每 2 小時一輪、不合併（額度用得平均、失敗有下一輪補上；每次呼叫的則數才影響判讀品質，輪數不影響）；開盤前檢查直接讀已判讀好的隔夜新聞、不另外呼叫 AI，只需先在本機量每輪的則數與耗時，確認開盤前那一輪來得及完成，來不及就把它提早。美股指數的畫面從大盤頁移到這裡。
- **每日主動通知**：資料跑完後通知當日名單、追蹤中觸發進場或跌破停損的標的。屬對外操作，管道與授權要使用者決定。
- **實際交易紀錄**：記錄使用者實際的買賣，對照「照名單做」與「實際做」的差別。
- **事件研究**：用已有的重大訊息與月營收公布日，量特定事件之後 5／20 日的超額報酬，同時檢驗新聞 AI 方向判讀有沒有用。
- **以模型組合特徵**：取代人訂的權重。兩年資料容易只記住這段歷史，等歷史回補後再評估。

不做：沒有證據支持的新技術指標或進場條件；更多 AI 生成的說明文字。

### 順序與取捨


- 階段一跑完前不開新的「對現行兩條規則加減條件」的研究單（#318、#546、#567、#598 四輪的差距都在雜訊內）；連續兩輪沒有新的證據就停手回報（[研究規則](spec/evidence.md#研究規則)）。
- 畫面與策略並行。畫面方向為「盤後終端」（使用者 2026-11-11 選定）：圖優先、資訊密、文字少。第 1 步是個股頁 K 線的規則價位線（[#617](https://github.com/YiCheng0608/stock-lab/issues/617)）；第 2 步是今日名單改成左清單（走勢線、價位尺）右圖，並一併改名：主導航「今日可買→今日名單」「觀察中→我的追蹤」「策略說明→策略與成績」，個股頁分頁「圖表與指標→走勢」「法人籌碼→籌碼」「研究條件→進出場」「資料說明→資料來源」；之後是個股頁圖表上移、觀察中頁重排、分數與強弱改用圖形、每頁資料日期只標一次。改版與改名同一張單做，同步改 [UI_COPY_SPEC](UI_COPY_SPEC.md)、[DESIGN_SYSTEM](DESIGN_SYSTEM.md) 與 verify 檢查。
- 「今日可買」改名為「今日名單」是因為目前沒有證據支持「可買」；成績單顯示名單穩定贏過同日母體後可以改回。
- 券商分點以免費公開來源不可行（[#548](https://github.com/YiCheng0608/stock-lab/issues/548)：官方逐檔日報表每檔要驗證碼且條款禁止自動化，FinMind 分點資料只限付費會員），維持不做。集保戶股權分散表現階段不收集：開放資料只保留當週、歷史補不回來，要累積數月才能驗證，排在後面（使用者 2026-11-11）。擴充資料來源本身是歡迎的；要不要納入一項資料，看兩件事：對之後的報酬有沒有預測力、現在驗證得了嗎（[策略證據](spec/evidence.md)），不看它多久更新一次。每日資料決定進出場的時機，月營收、季報這類更新慢的資料用來篩選值得看的股票。

## V1 範圍基線（2026-10-17 核定）

使用者於 2026-10-17 核定。V1 定位為 **研究輔助 app**：像一般股票 app 可查個股資訊，並以國內外新聞與技術指標給出建議進出點，每日排程更新熱門族群、候選股票與進出點。

- **範圍**：台灣上市（TWSE）與上櫃（TPEx）全部普通股；ETF 收集並分類，但不進候選清單。
- **使用者需求對應**：N1 個股資訊（K 線、成交量、均線、MACD、RSI、KD、布林、籌碼、新聞）；N2 依新聞與技術指標分析建議進出點；N3 每日排程更新國內外新聞、熱門族群與熱門股候選，並據此更新進出點。
- **顯示原則**：有資料就顯示並標來源與資料日期；缺資料留空並標「無資料」，不補零、不混來源、不以較早或未來日替代；LLM 推論與來源事實分欄並標「推論」。
- **資料與保存**：官方 TWSE／TPEx 整批下載為每日主來源（行情、法人、融資、官方事件），FinMind 補歷史與缺口；先回補 2～3 年日線；指標每日批次計算標量，不預存陣列；raw 回應保留 30～90 天；單一 SQLite 檔（全市場 10 年行情＋籌碼＋索引約 2.5 GB）。
- **新聞**：每日排程抓國內與國際免費公開來源進 DB；保存來源、時間、標題、摘要、關聯個股／族群、方向判讀、原文連結，正文可選；去重與時間規則依[新聞規格](NEWS_SPEC.md)。
- **熱門族群**：官方產業分類＋人工維護題材表（版本化、含生效／失效日）為底，新聞聚合提出新題材建議供人工納入；`hot_group_v1` 五分項沿用，產業與題材各算一榜並可切換。
- **進出點**：規則式為主，保留 `breakout_v1`／`pullback_v1` 原公式與版本，新增指標條件以升版方式加入；技術＋籌碼＋新聞情緒評分只用於排序；LLM 只寫說明文字；進場區／停損／目標／RR 由策略與 ATR 推算。
- **指標**：MA5／10／20／60／120、MACD(12,26,9)、RSI(6,12)、KD(9,3,3)、布林(20,2)、成交量與量均；參數變更以版本記錄。

使用者層級決策記在[治理 Issue #1](https://github.com/YiCheng0608/stock-lab/issues/1)，必要任務納入 [V1 milestone](https://github.com/YiCheng0608/stock-lab/milestone/1)，整體發布由 V1-G7 與 milestone 承接（已完成，見 [V1 已完成](#v1-已完成)）。任務與 gate 的對應見[工作手冊](WORKFLOW.md#版本範圍與完成判定)。
