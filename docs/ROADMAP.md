## 接下來的順序：近期產品里程碑

使用流程：**今日（熱門族群、明日候選、重點新聞）→ 族群 → 個股（圖表、指標、進出點、新聞）→ 計畫 → 追蹤回看**。建置優先方向：**M1 全市場每日資料與個股頁 → M2 新聞管線與熱門族群 → M3 進出點、候選清單與追蹤**。統籌在 GitHub 依實際可用依賴選單；三條線可按[資料與功能拆線](GITHUB_WORKFLOW.md#資料與功能拆線)並行。

| 里程碑 | 完成後的使用者操作 | 核心條件 |
| --- | --- | --- |
| M1 全市場資料與個股頁 | 查任一上市／上櫃普通股的日／週 K 線、成交量、MA5／10／20／60／120、MACD、RSI、KD、布林、三大法人 5／20 日淨超與融資變化；資料每日自動更新到最近交易日。 | 官方整批 collector 每日排程跑通並寫入 DB；回補 2～3 年日線；指標每日批次計算為標量；個股頁指標面板可切換；每個數值顯示資料日期與來源。 |
| M2 新聞與熱門族群 | 看國內／國際新聞清單、每則的關聯個股／族群與正負向判讀；看產業／題材兩層熱門族群榜、成員與熱度走勢。 | 新聞排程每日進 DB（來源、時間、標題、摘要、原文連結）；LLM 摘要／關聯／方向判讀分欄保存並標推論；題材表版本化含生效日；hot_group_v1 跨全市場每日計算，產業與題材各算一榜。 |
| M3 進出點、候選與追蹤 | 個股頁看進出點卡（策略、進場區、停損、目標、RR、觸發條件、依據）；今日頁看明日候選 10～20 檔與理由；把候選或個股加入追蹤，每日自動更新觸發／到期／結果並回看。 | 規則式策略每日對全市場評估；評分排序含技術、籌碼、新聞情緒；LLM 說明文字標推論；追蹤計畫保存於 DB 並由排程更新；不宣稱勝率。 |

## V1 範圍基線（2026-10-17 核定）

使用者於 2026-10-17 核定。V1 定位為 **研究輔助 app**：像一般股票 app 可查個股資訊，並以國內外新聞與技術指標給出建議進出點，每日排程更新熱門族群、候選股票與進出點。

- **範圍**：台灣上市（TWSE）與上櫃（TPEx）全部普通股；ETF 收集並分類，但不進候選清單。
- **使用者需求對應**：N1 個股資訊（K 線、成交量、均線、MACD、RSI、KD、布林、籌碼、新聞）；N2 依新聞與技術指標分析建議進出點；N3 每日排程更新國內外新聞、熱門族群與熱門股候選，並據此更新進出點。
- **顯示原則**：有資料就顯示並標來源與資料日期；缺資料留空並標「無資料」，不補零、不混來源、不以較早或未來日替代；LLM 推論與來源事實分欄並標「推論」。
- **資料與保存**：官方 TWSE／TPEx 整批下載為每日主來源（行情、法人、融資、官方事件），FinMind 補歷史與缺口；先回補 2～3 年日線；指標每日批次計算標量，不預存陣列；raw 回應保留 30～90 天；單一 SQLite 檔（全市場 10 年行情＋籌碼＋索引約 2.5 GB）。
- **新聞**：每日排程抓國內與國際免費公開來源進 DB；保存來源、時間、標題、摘要、關聯個股／族群、方向判讀、原文連結，正文可選；去重與時間規則依[新聞規格](NEWS_SPEC.md)。
- **熱門族群**：官方產業分類＋人工維護題材表（版本化、含生效／失效日）為底，新聞聚合提出新題材建議供人工納入；`hot_group_v1` 五分項沿用，產業與題材各算一榜並可切換。
- **進出點**：規則式為主，保留 `breakout_v1`／`pullback_v1` 原公式與版本，新增指標條件以升版方式加入；技術＋籌碼＋新聞情緒評分只用於排序；LLM 只寫說明文字；進場區／停損／目標／RR 由策略與 ATR 推算。
- **指標**：MA5／10／20／60／120、MACD(12,26,9)、RSI(6,12)、KD(9,3,3)、布林(20,2)、成交量與量均；參數變更以版本記錄。

使用者層級決策記在[治理 Issue #1](https://github.com/YiCheng0608/stock-lab/issues/1)，必要任務納入 [V1 milestone](https://github.com/YiCheng0608/stock-lab/milestone/1)，整體發布由 V1-G7 與 milestone 承接。任務與 gate 的對應見[工作手冊](GITHUB_WORKFLOW.md#版本範圍與完成判定)。

| 能力 gate | V1 必要邊界與驗收要點 |
| --- | --- |
| V1-G1 全市場每日資料與排程 | 每日排程以官方整批來源更新全部上市／上櫃普通股的日行情、三大法人、融資與官方事件並寫入 DB；失敗可重跑且冪等；回補至少 2 年日線；每筆保留來源、資料日期與擷取時間；缺日與來源失敗分開記錄，不補零。 |
| V1-G2 個股頁圖表與指標 | 任一普通股可看日／週 K 線、成交量、MA5／10／20／60／120 與可切換的 MACD／RSI／KD／布林面板；指標由保存的日線每日批次計算，公式與參數版本化；資料不足的指標留空並說明根數不足；頁面顯示資料日期與來源。 |
| V1-G3 新聞管線 | 每日排程抓國內與國際新聞進 DB，去重、保留來源與時間；LLM 產出摘要、關聯個股／族群、正負向判讀並分欄保存、標推論與模型／提示版本；新聞頁可分國內／國際瀏覽、看關聯與原文連結；個股頁顯示該股新聞時間線。 |
| V1-G4 族群定義與熱門族群榜 | 官方產業分類每日更新；題材表版本化、含生效／失效日與來源證據；新聞聚合的新題材建議標待核實，不自動進榜；`hot_group_v1` 對產業與題材各算一榜，族群頁可看成員、熱度走勢與相關新聞；今日頁顯示熱門族群 Top 10。 |
| V1-G5 進出點與每日候選清單 | 規則式策略每日對全市場評估，給出成立／未成立／資料不足與進場區、停損、目標、RR；評分排序含技術、籌碼、新聞情緒且各分項可見；今日頁產出明日候選 10～20 檔並附理由與所屬族群；LLM 說明文字標推論；零候選是合法結果，不湊名單。 |
| V1-G6 計畫與追蹤回看 | 使用者可把候選或個股加入追蹤並保存計畫（策略、價位、建立日、版本）；排程每日更新待觸發／已觸發／到期／失效狀態與結果；行動頁可回看歷史結果；計畫、模擬結果與實際持倉分開，不宣稱真實成交或勝率。 |
| V1-G7 發布驗收 | 已整合 master 上排程連續跑過至少 5 個交易日並產出候選與新聞判讀；五個主導航以真實 DB 資料完成「今日→族群→個股→追蹤」端到端操作並經獨立 review；required CI、文件與版本證據齊全；阻擋缺陷為 0；統籌確認後才關 milestone。部署另需授權。 |

完整公式以[canonical 規格](V1_SPEC.md)為準，新增指標條件以升版加入，不改寫既有版本結果；分類與有效期間依[分類契約](INDUSTRY_CLASSIFICATION.md)。

後版保留：主力／券商分點、九類法人方向、AI 預測與校準勝率、做空、擴市場。新增市場、策略、能力或降低 AC 另由使用者決策，pending 不默認納入。

## 保留的產品取捨

- 盤後 long、最早 T+1、數天至數週；精確期間與做空待決，T+5／T+20 是追蹤窗口，不當退出日。
- 只用免費公開來源，選用與限制見[資料來源](DATA_SOURCES.md)。
- 保留研究、模擬追蹤、持倉風險與來源追溯。
- LLM 只做新聞摘要、關聯、方向判讀與進出點說明文字，結果標推論；經本機 Claude Code 無介面模式用使用者訂閱帳號呼叫，不用 API 計費。勝率顯示條件見[產品規格 §8](PRODUCT_SPEC.md#8-ai-的角色與完成條件)。
- 第一版不含自動下單、盤中即時交易、無來源 AI 報價與未驗證勝率。本機排程屬 V1 範圍；正式 DB、採購、帳戶、部署仍須個別授權。
