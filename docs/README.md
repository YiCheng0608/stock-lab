方向與版本範圍寫 ROADMAP，視覺寫 DESIGN_SYSTEM，角色與原則寫 AGENTS，操作與模板寫 GITHUB_WORKFLOW，精確行為寫主題契約；其他處只放連結。功能完成的同一個 PR 更新文件。
