# 股票研究詞彙表

更新：2026-09-16。本文只提供日常研究所需的簡明詞義與誤讀界線；規則公式見 [V1_SPEC](V1_SPEC.md)，文案、單位與 reason code 見 [UI_COPY_SPEC](UI_COPY_SPEC.md)，能力狀態見 [ROADMAP](ROADMAP.md)。詞彙出現在 UI 或本文，不代表對應資料或模型已上線。

## 使用方式與資料結構

詞彙資料至少有 term_id、名稱、別名、分類、白話說明、用途、限制、相關詞與版本。詞彙按鈕可由滑鼠、觸控、Enter／Space 開啟，Esc 關閉並把焦點送回觸發點；定義不能只靠 hover 或顏色。資料不足時，解釋也要明說本頁不能用該指標下結論。

## 技術與價位

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 突破 | 收盤高於前段期間壓力高點；需同看量能、族群與籌碼。T 日成立不等於成交，最早 T+1。 |
| 回踩 | 上升趨勢中回到均線附近整理；沒有 MA20／MA60 或足夠資料時不能判斷。 |
| MA20／MA60 | 最近 20／60 個交易日收盤均值，是落後指標，不預測未來。 |
| ATR | True Range 取 high-low、abs(high-prev_close)、abs(low-prev_close) 最大值後平滑。需說明暖機方法；現行 worker 的 atr14 仍只平均 high-low。 |
| 支撐／失效點 | 支撐是可能承接區，失效點表示策略前提被推翻；跳空或停牌可能跨越價位，不能保證成交。 |
| 目標價 | 預先定義的追蹤參考，不是必達預測；應與進場、失效和成本一起閱讀。 |
| 風險報酬比（RR） | 目標距離相對於失效風險的比值；v1 第一目標最低 1.5。它不含成交機率、滑價或流動性。 |
| 量能／量比 | 當期成交量相對歷史均量；單日異常量不能單獨作結論。 |
| 最近收盤 | 最新可驗證交易日的收盤，必須附日期；不是即時現價。 |
| 漲跌幅 | 最近收盤相對前一個相鄰、同 basis 的可信收盤之變動；缺資料寫「漲跌幅待核實」，不能補 0%。 |
| T+1 | 訊號日後第一個可交易日；仍受停牌、流動性、跳空與觸發條件限制。 |

## 籌碼與市場

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 三大法人 | 外資、投信與自營商的交易彙總；不包含廣義券商或分點。缺值不能補 0，宜看多日淨額相對週轉。 |
| 個股籌碼 | 個股法人買賣、融資與可用交易資訊；不是所有投資人的持倉，也不能單獨預測價格。 |
| 外資 | 日常頁對交易所「外資及陸資」合計欄位的簡稱；不等於單一外資機構的持倉或意圖，來源／稽核層保留正式口徑。 |
| 投信 | 國內投信買賣超；看多日趨勢，不能從單日推論未來。 |
| 自營商 | 券商自營部門買賣超；應與外資、投信分開，欄位本身不揭示交易目的，也不代表所有券商或分點交易。 |
| 淨買超／淨賣超 | 買入減賣出的金額或數量；需附單位、來源與窗口，正負不等於必然方向。 |
| 融資變化 | 融資餘額變動；需確認相鄰官方日期，快速增加不是單獨的多空結論。 |
| 週轉額 | 交易金額／流動性規模，可用來標準化法人流，但不保證可成交。 |
| TAIEX | 臺灣加權指數，是 hot_group_v1 的相對報酬基準。 |
| 廣度 | 群組中跑贏基準的合格成員比例；成員或歷史不足時不計分。 |
| 熱門族群 | 五個 v1 component 完整且相對較強的群組；partial、missing 或成員不足不能稱熱門，也不保證上漲。 |

## 資料品質與來源

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 資料截止日（as_of） | 資料代表的最後可驗證交易／事件日期；最新蒐集時間不等於市場資料已更新。 |
| 蒐集時間（collected_at） | 系統取得來源資料的時間；不等於新聞發布、事件發生或歷史可得時間。 |
| 發布時間／事件時間 | 來源直接提供的發布時間或可稽核事件時間／日期；缺失時顯示「來源時間未提供」。 |
| 時間待核實 | 來源時間衝突或關係無法證明；不進預設最新串流，也不自動成為交易理由。 |
| first_available_at | 有證據支持某版本第一次可取得的時間；不能以事件日或模型猜測。 |
| 決策時間 | 策略完成判斷的時間；必須晚於必要資料的 availability。 |
| Raw provenance | 原始 payload、endpoint、雜湊與擷取紀錄，提供追溯但不保證來源完整正確。 |
| 資料完整度 | 只對具名用途成立，不能用模糊「完整」跨域推論。 |
| 來源擷取完整 | 可追溯地取得來源 payload；不代表欄位、歷史窗口或策略輸入完整。 |
| 當日行情完整 | 指定標的／市場／日期的 OHLCV 可驗證；不代表籌碼、族群或歷史完整。 |
| 策略判斷資料完整 | 某一研究條件的行情、基準、籌碼與族群輸入可用；不代表績效或另一條策略完整。 |
| 完整觀察條件 | 輸入完整但進場條件未成立；沒有 entry／target／RR 是正常。僅 contract 提供合法等待價位時顯示等待條件。 |
| 策略判斷資料待補 | 某策略缺少必要輸入；只阻擋該策略，不能覆寫同卡另一條完整條件。 |
| fail closed | 無法驗證時拒絕動作，不猜測或補值。 |
| 資料品質診斷 | 顯示缺欄、失敗 run、raw 與檢查結果的技術頁；不是主要研究結論。 |

## 策略、追蹤與研究結果

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 訊號列 | 單一策略、標的與日期的規則輸出；多策略可有多列，不等於重複買賣建議。 |
| 行動摘要 | 將同一標的的策略、持倉、品質與價位聚成一張卡；是產品聚合，不是新策略。 |
| 條件進場 | 資料與價位完整後，僅在觸發條件成立時研究進場；須有觸發、失效、目標與 T+1。 |
| 等待突破／等待回踩 | 完整 observation 且 contract 有合法門檻／區間時的狀態；等待價位不是 entry，不能自行由高點或 MA 推造。 |
| 暫無研究條件 | 資料完整但條件未成立，也沒有合法等待價位；不是資料待補或多空訊號。 |
| 持有觀察／減碼退場 | 使用者既有持倉的風險狀態；使用者 stop 與策略 invalid 必須分開，且不會自動下單。 |
| Tracking | T+1 後逐日記錄條件與價格結果；停牌或缺資料時可能沒有可比結果。 |
| Settlement | T+5／T+20 固定窗口的研究結算；不是即時退出指令。 |
| incomparable | 停牌、缺價格或同日 stop／target 順序未知，無法公平判定；不可硬分成勝敗。 |
| Technical backtest | 固定規則的歷史 replay，用於稽核與樣本描述；短樣本標 `insufficient_sample`。 |
| Walk-forward／OOS | 用未參與設計的後續／獨立資料驗證；目前尚未完成。 |

## 交易單位與持倉

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 股 | DB／API 的 canonical 整數數量；市值與損益用精確股數計算。 |
| 張 | 台股顯示單位，1 張＝1,000 股；只改顯示，不改儲存與計算。 |
| 零股 | 少於 1 張或整張之外的餘數；250 股顯示「250 股（零股）」，不能截斷。 |
| 每股平均成本 | 持倉成本除以精確股數，單位為各標的報價幣別的元／股；API 未提供 currency 時不猜成新臺幣。它不等於每張成本或停損建議。 |
| 成交量 | 指定日成交股數；UI 可換算張，策略仍讀精確原值。缺值、非有限值或未核實日期不補 0。 |

## ETF

| 詞彙 | 定義與使用限制 |
| --- | --- |
| ETF | 交易所交易基金；先看類別、曝險、槓桿、流動性與成分，不能視為同質商品。 |
| 大盤／股利／產業／主題／商品型 ETF | 可套一般 v1，但仍受全部品質與 eligibility gate。 |
| 債券／槓桿／反向型 ETF | 仍收集與分榜；暫不可產生一般 breakout_v1／pullback_v1 actionable signal。 |

## 題材、短線資金與 AI（新增內容，程式待同步）

| 詞彙 | 定義與使用限制 |
| --- | --- |
| 官方產業／市場題材 | 前者是交易所分類；後者可跨產業且多重歸屬，需證據與有效期，不是官方認證或買點。 |
| 熱度變化／領漲集中度 | 描述群組強弱變化及是否由少數成員主導；需同看窗口、廣度、成員數與完整度。 |
| 現股當沖比例 | 股票當日沖銷活動占指定成交基準的比例；不能推論特定法人比例。 |
| 券商分點 | 交易通道彙總，不等於單一投資人或外資機構。 |
| 主力 | 市場俗稱，沒有由現行官方法人或分點欄位直接對應的單一身分；後續「主力進出」是由可驗證分點資料計算的統計指標，不是身分辨識。見[個股頁 §8](STOCK_RESEARCH_PAGE.md#8-籌碼三部分後續待做)。 |
| 疑似隔日沖／分點反轉 | 大買後次日轉賣等可重現特徵；不能證明同一批股票、同一人或未來行為。 |
| 事件新資訊 | 相對當時已知消息新增的事實或更正；轉載不算新事件。 |
| AI 摘要／影響推論 | 摘要整理原文，推論描述可能影響鏈；兩者都要標示方法、引用與 unknown，不能冒充官方原文或績效。 |
| 校準機率 | 在固定事件、期間與樣本外驗證下，預測機率和觀察頻率的對應；固定 0.75 或模型自評不算。 |
| 交易計畫／不追價上限 | 事先定義觸發、區間、失效、退出、期限與拒絕追價條件；計畫不是成交。 |
| 時間停損／事件失效 | 期限屆滿或支持前提失效的明確規則；不能事後改寫理由。 |
| 部位風險／題材曝險 | 單筆損失與相關持倉集中程度；同一股票不得因多題材重複計算，預算未知不給張數。 |
| 前瞻模擬交易 | 先固定當日計畫再記未來觸發、成交與結果；保留未成交和零候選，且不等於真實成交。 |
