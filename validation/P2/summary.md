- 假設：基本面：三率三升；每季法定期限的事件日，`margins_up`（最新一季單季毛利率、營益率、淨利率都高於上一季，也都高於去年同季）成立，以雜湊取 20 檔、不排序；持有到下一個事件日；N＝20、持有到下一個事件日

- 期間：訊號日 2020-03-31 起，有淨值的交易日 2020-04-01～2024-09-27，共 1097 個交易日
- 退化：最新一季（`announcement_date` ≤ T 的季報列中期末最晚的一季，EPS 是 null 的列也算，和 K2 不同）不是事件日對應的那一季、q、q−1、q−4 與算單季要用的前一季中任一列的 `report_format` 不是 `general`（`report_format` 是 null 的列算欄位缺）、任一列不在或四個欄位任一欄缺（毛利先用 `營業毛利（毛損）淨額`，沒有這一欄時用 `營業毛利（毛損）`），或任一季的單季營收 ≤ 0 時，不符合；6 個比較中任一個不是嚴格較高（含相等）時也不符合；符合的不足 20 檔時餘額留現金
