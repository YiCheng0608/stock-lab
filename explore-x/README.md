# #867 探索段：X3、X4、X7（explore_research 第 2 版）

## 先讀：下市股月營收缺口造成的偏差（有利於假設）

照 [#867 決定 7032683717](https://github.com/YiCheng0608/stock-lab/issues/867#issuecomment-7032683717)（選項 A），本次照登記原樣跑：定義、判定、門檻、工具版本都沒動。工具產出的 `explore.md`／`explore.json` 原樣，沒有改；偏差寫在這份 README。

- **缺口**：研究 DB 在下市股上大多沒有月營收（#786「補完後的缺口」，主要是 `not_public` 130 檔）。工具把條件缺值當成不符合（`explore_research.passes`），所以這些股票在選股前就被排除，基準母體裡卻有它們。
- **大小**（[設計提問 7032659972](https://github.com/YiCheng0608/stock-lab/issues/867#issuecomment-7032659972) 的唯讀量測，[design/](https://github.com/YiCheng0608/stock-lab/tree/pr-assets/867/design)）：

| 假設 | 探索段母體裡的下市股 | 其中因缺值被排除 | 通過條件的名單中下市股：實際 → 若有資料（估） |
| --- | --- | --- | --- |
| X3 | 7.6% 的檔日 | 91% | 0.7% → 約 6.7% |
| X4 | 7.9% | 91% | 0.7% → 約 7.0% |
| X7 | 8.2% | 92% | 0.6% → 約 6.0% |

- **方向**：
  - 假設的名單幾乎沒有之後下市的公司，基準卻有，而下市前的公司多半表現差，所以偏差有利於假設。
  - 例外：`not_public` 裡合併消滅的公司（例如 2888 新光金）可能有收購溢價，方向相反；比例沒有查證。
- **驗證段的缺口小很多**：母體 2.2%，名單約 1.4% → 0.6%。
- **對照**：探索通過的假設（本次是 X4），提問驗證段時附「基準去掉當天缺該假設基本面欄位的下市股」的超額，只列出、不判定。
