## 風險（AI 推論）

- 這是根據一個月、樣本很少的推論，不保證新版本比較好。要先以 shadow 和 premarket_v1 並行記錄、對過答案再換版。
- p1 的修改會讓「美股與夜盤方向相反」的日子幾乎都判 neutral。萬一某段期間美股訊號比夜盤可信，命中率可能下降；而且 neutral 的命中取決於 band（0.005），會受行情波動大小影響。
- 12-04 的對照案例和 sessions 資料互相矛盾：sessions 記錄 market_output 是 bullish，case 的 outcome 卻是 neutral，理由文字也寫「推論台股開高」，跟 stance 不一致。這筆對照的可靠度不明，建議先查資料管線。
- p2 的修改可能讓真正重大的單一則利空被當成「價量籌碼相反」而沒有 defer。輸入只給新聞標題，看不出利空有多嚴重；若實際案例中重大利空占多數，defer 的保護作用會變弱。
- 對照案例 9911、9912 的理由寫了「利空新聞」，輸入裡卻沒有 news 欄位，refs 也只引用 chips，已經違反規則 1。這只有 2 筆、而且是對照案例，依規則沒有修改，但建議另外追蹤是否有編造新聞的情形。新規則要求 defer 理由要寫出各訊號，也可能讓這類編造更明顯或更常出現。
- 判錯案例的輸入數值完全一樣（return_5d 0.04、volume_ratio 1.8、foreign_5d 1200、超額報酬約 +5%），看起來像合成或重複的資料，代表性可能不夠；月統計中 defer 的平均報酬（0.012）高於 keep（0.004），但 defer 只有 n=40，不宜過度解讀。
