- 判定：**沒有通過（探索段）**

- 期間：訊號日 2014-05-15 起，有淨值的交易日 2014-05-16～2019-12-31，共 1384 個交易日
- 退化：最新一季（`announcement_date` ≤ T 的季報列中期末最晚的一季，EPS 是 null 的列也算）不是事件日對應的那一季、q、q−4 與算單季要用的前一季中任一列的 `report_format` 不是 `general`（`report_format` 是 null 的列算欄位缺）、任一列不在或 `所得稅費用（利益）`、`營業收入` 任一欄缺，或 rev(q−4) ≤ 0 時缺值、排最後；tax(q)＝tax(q−4) 時 `tax_mom`＝0，照值排序；有值的不足 20 檔時以缺值的依雜湊補，母體不足 20 檔時餘額留現金
